# 연도 추가하는 법

새 연도를 추가하려면 `public/exhibitions/` 안에 **연도 이름으로 된 폴더**(예: `2027`)를 하나 만들고, 이 `exhibition-template` 폴더의 `info.json`을 복사해 값을 채우고, 아래 표의 이미지·영상 파일을 같이 넣으면 됩니다. 코드는 건드릴 필요 없습니다 — 폴더가 있으면 자동으로 사이트에 반영됩니다.

## 필요한 파일 4개

| 파일명 | 내용 | 형식 |
|---|---|---|
| `poster.jpg` 또는 `.png` | 포스터 (연혁 섹션 + 포스터 그리드에 공용으로 쓰임) | JPG/PNG |
| `invitation.png` | 초대장 (홈 화면 쌓임 애니메이션용) | **투명 배경 PNG, 1320×1320** |
| `moving-poster.mp4` | 무빙포스터 (연혁 섹션, 467:660 비율 칸에 꽉 차게 잘려 보임) | **MP4(H.264)만 인식됩니다** |
| `info.json` | 전시 타이틀, 날짜, 장소, 키컬러 | JSON |

초대장에 테이프·클립·집게 같은 사물을 붙였다면 아래 파일도 같이 넣어주세요 (선택).

| 파일명 | 내용 | 형식 |
|---|---|---|
| `invitation-plain.png` | 사물 레이어만 끄고 내보낸 **종이만 있는** 초대장. 초대장 넘겨보기에서 카드가 옆으로 서 있을 때 쓰이고, 정면으로 펴지면 사물이 다시 나타납니다 | `invitation.png`와 **같은 캔버스·같은 위치**, 투명 배경 PNG 1320×1320 |

파일 이름은 위 표와 **정확히 같아야** 인식됩니다 (대소문자 포함). 하나가 빠져도 에러는 안 나고 해당 자리만 비거나 대체 이미지로 나옵니다 — 무빙포스터가 없으면 포스터 이미지가 대신 보입니다.

## 초대장 규격

- **1320×1320 정사각형, 투명 배경 PNG**로 내보내 주세요. 사이트에서는 660×660(1440 화면 기준) 칸에 2배 해상도로 들어갑니다.
- 초대장 실물은 캔버스 가운데에 두고, 테이프·그림자 등 바깥 요소까지 캔버스 안에 들어오게 해주세요. 투명한 바깥 여백은 해마다 달라도 괜찮지만, 연도별로 겹쳐 쌓이므로 비슷한 크기로 맞추면 보기 좋습니다.
- 배경이 흰색/검은색으로 채워져 있으면 쌓일 때 네모난 판처럼 보입니다. 꼭 투명 배경으로 내보내 주세요.

## info.json 작성법

```json
{
  "titleKo": "THIS IS NOT\nGRADUATION",
  "titleEn": "",
  "openingDate": "2027-11-11 (수) 17:30",
  "venue": "경희대학교 국제캠퍼스 예술디자인대학 2층 A&D HALL",
  "keyColor": "#1980FF",
  "href": "https://example.com/2027"
}
```

- **타이틀**: 사이트에는 `titleEn`이 있으면 `titleEn`, 비어 있으면 `titleKo`가 표시됩니다. 둘 중 사이트에 보일 쪽에 정확한 표기를 넣어주세요.
- **줄바꿈**: 연혁 섹션의 큰 타이틀을 두 줄로 나누고 싶은 위치에 `\n`을 넣으세요 (예: `"THIS IS NOT\nGRADUATION"`). 홈 화면의 `<타이틀>` 안내에서는 줄바꿈 없이 한 줄로 이어져 보입니다.
- **href**: 그해 온라인 전시 사이트 주소(`https://`로 시작). 넣으면 포스터·초대장의 "VISIT WEB SITE" 링크와 홈 화면 VISIT 버튼이 이 주소로 연결됩니다. 아직 사이트가 없으면 이 줄을 지우거나 `""`로 두세요 — 그 연도는 "VISIT WEB SITE"가 눌러도 나타나지 않습니다.
- **날짜·장소**: 기록용으로 채워주세요 (현재 화면에는 표시되지 않음).
- 따옴표(`"`)와 쉼표(`,`)가 하나라도 빠지면 파일 전체를 못 읽습니다. 마지막 항목 뒤에는 쉼표를 넣지 마세요.

## 키컬러

`info.json`의 `keyColor`에 그해 대표색(보통 초대장·포스터의 메인 컬러)을 `#RRGGBB` 형식으로 넣으면 홈 화면 "VISIT ○○○○ ON-LINE EXHIBITION" 링크 색이 그 색으로 바뀝니다. 비워두면 흰색으로 나옵니다.
검은 배경 위에 글자로 쓰이니 너무 어두운 색(남색·짙은 갈색 등)은 피해주세요.

## ⚠️ 무빙포스터는 꼭 MP4로 변환해서 올리세요

프리미어/애프터이펙트에서 그냥 내보내면 보통 `.mov`(퀵타임, ProRes) 파일이 나오는데, 이건:
- 웹 브라우저에서 재생이 안 될 수 있음 (크롬 등 미지원)
- 용량이 엄청 큼 (10초짜리가 100MB 넘기도 함)

**MP4로 변환하고 올려주세요.** 변환 안 된 파일을 올리면 코드가 그냥 못 찾아서 무빙포스터 없이(포스터 이미지만) 표시됩니다 — 에러는 안 나지만 영상이 안 보여요.

변환 방법:
- Claude(졸준위 공용 계정 세션)에게 변환 요청하면 자동으로 처리해줌 (권장)
- 또는 직접: [HandBrake](https://handbrake.fr/)(무료 프로그램)로 `.mov` 파일을 열어서 Format을 MP4로, Video Codec을 H.264로 설정 후 내보내기

참고로 2024년 영상은 105MB 원본을 MP4로 변환해서 **765KB**가 됐습니다 — 화질 차이는 거의 없습니다.
