# KHID 졸업전시 아카이브

경희대학교 산업디자인학과 졸업전시를 **해마다 한 칸씩 쌓아 두는 사이트**입니다.
주소: **https://khid.exhibit.khu.ac.kr**

이 문서는 **다음 기수 졸업준비위원회(졸준위) 웹 담당**에게 넘겨주는 안내입니다. 개발을 해 본 적이 없어도 괜찮습니다.
- 여러분이 할 일은 **디자인 결과물을 만들고, 정보 몇 가지를 받아 오는 것**입니다.
- 파일 이름 정리, 폴더에 넣기, 영상 변환, 사이트에 올리기는 **Claude(졸준위 Claude 계정 혹은 기타 ai 툴)가 합니다.**
- GitHub·Vercel 계정도 그대로 물려받으니 새로 만들 필요가 없습니다.

---

## 1. 한눈에 보기: 매년 할 일

1. 아래 **디자인할 것 4가지**를 만든다.
2. 아래 **받아 올 정보**를 졸준위에서 확정받는다.
3. 2학기 개강 전후로 작업을 완료 해두면 좋습니다. 적어도 전시 시작 **1~2주 전까지** Claude에게 넘기고 "아카이브에 올해 추가해줘"라고 말한다.

이것으로 끝입니다. 전시 기간에 사이트 문구가 바뀌는 것은 날짜에 맞춰 자동으로 됩니다.
그해 전시 사이트로 가는 VISIT 버튼도 `khid.grad.khu.ac.kr/연도`로 자동 연결되니 주소를 따로 알려 줄 필요가 없습니다.

## 2. 먼저 알아 둘 것: 사이트는 두 개입니다

| | **아카이브 사이트** (이 문서) | **연도별 전시 사이트** |
|---|---|---|
| 주소 | `khid.exhibit.khu.ac.kr` | `khid.grad.khu.ac.kr/2026`, `/2027` … |
| 무엇 | 모든 연도의 초대장·포스터·무빙포스터를 모아 둔 **목록** | 그해 디자이너·작품을 보여 주는 **그해 전시 사이트** |
| 매년 할 일 | 새 디자인 없음. **올해 자료만 추가** | 매년 **새로 디자인하고 개발** |

둘은 **링크로만 이어져** 있습니다. 아카이브에서 그해 칸의 "VISIT" 버튼을 누르면 그해 전시 사이트(`khid.grad.khu.ac.kr/연도`)로 넘어갑니다. 연도별 전시 사이트는 매년 같은 도메인 뒤에 `/연도`를 붙이는 규칙이라, 이 링크는 자동으로 만들어집니다.
연도별 전시 사이트를 만드는 방법은 GitHub 저장소 `khuid/khid-grad`의 안내(README)에 따로 있습니다.

## 3. 디자인할 것 (4가지 + 대표색 설정)

**규격을 지켜 주세요.** 

| | 무엇 | 사이트에서 보이는 위치 | 규격 | 비고 |
|---|---|---|---|---|
| ☐ | **초대장 이미지** | Phase 1: 연도별 초대장이 쌓이는 더미 맨 위 | 1320×1320px, 투명 배경 PNG | **기울기 없이 똑바로** 놓은 이미지로 만들기. 더미에서의 위치·기울기 값은 Claude가 조절함. 초대장은 캔버스 가운데에 두고, 테이프·그림자 같은 바깥 요소도 캔버스 안에 들어오게. 배경을 흰색·검은색으로 채우면 네모난 판처럼 보이니 꼭 투명으로 |
| ☐ | **사물을 뺀 초대장 이미지** (해당될 때만) | Phase 1: 더미를 눌렀을 때 나오는 초대장 넘겨보기 | 1320×1320px, 투명 배경 PNG | 초대장에 테이프·클립·집게 같은 **사물을 붙였을 때만** 필요. 사물 레이어만 끄고 초대장 이미지와 **같은 캔버스·같은 위치**로 한 장 더 내보내기. 사물이 없으면 만들지 않음 |
| ☐ | **포스터** | Phase 3: 포스터 모음 | 세로형, 가로 1100px 이상, PNG 또는 JPG | 인쇄용 원본을 그대로 줘도 됨(사이트가 화면 크기에 맞게 자동으로 줄여 보여 줌). 지난 포스터는 A 규격 비율(가로:세로 약 1:1.41, 예: 3508×4961px). 화면에서 가장 크게 보일 때 가로 약 520px이라 선명하게 보이려면 그 2배 이상 필요 |
| ☐ | **무빙포스터** | Phase 2: 연혁에서 연도를 고르면 재생 | 가로:세로 467:660, 영상(`.mov` 또는 `.mp4`) | 사이트에서는 467:660 칸에 꽉 차게 잘려 보이니 이 비율로 만들면 잘리는 부분이 없음. 변환은 Claude가 함 |
| ☐ | **대표색 1개** | Phase 1: "VISIT 연도 ON-LINE EXHIBITION" 버튼 색 | 색상 코드 (예: `#1980FF`) | 보통 초대장·포스터의 메인 색. 검은 배경 위에 쓰이니 너무 어두운 색(남색·짙은 갈색 등)은 피하기 |

## 4. 받아 올 정보

졸준위에서 **확정된 값**을 받아 Claude에게 그대로 전달하면 됩니다.

| | 정보 | 어디에 쓰이나 | 주의 |
|---|---|---|---|
| ☐ | **전시 타이틀** (사이트에 보일 정확한 표기) | 첫 화면 안내, 연혁 | 연혁에서 두 줄로 나눌 위치가 있으면 같이 알려 주기 (예: THIS IS NOT / GRADUATION) |
| ☐ | **전시 시작일** | 첫 화면 문구가 바뀌는 시점 | 아래 "첫 화면 문구" 참고 |
| ☐ | **전시 마감일 + 마감 시각** | 첫 화면 문구가 바뀌는 시점 | **해마다 날짜와 시각이 다릅니다.** 지난해 값을 쓰지 말고 꼭 그해 값으로. 예: 2026년은 11/16 **20시** 마감 |
| ☐ | 오프닝 일시·장소 | 기록용 (화면에는 안 보임) | 있으면 전달 |

### 첫 화면 문구는 날짜에 따라 저절로 바뀝니다
위에서 받아 온 시작일·마감 시각(한국 시간)을 기준으로 바뀝니다. 그날 따로 할 일은 없습니다.

| 시점 | 첫 화면 문구 |
|---|---|
| 전시 시작 전 (2학기 개강 쯤부터) | `UPCOMING EXHIBITION` (곧 열릴 전시) |
| 전시 기간 (시작 ~ 마감 시각) | `ONGOING EXHIBITION` (진행 중인 전시) |
| 마감 후 ~ 다음 해 자료를 올릴 때까지 | `LATEST EXHIBITION` (가장 최근 전시) |

## 5. 일정: 언제까지 무엇을

| 언제 | 할 일 |
|---|---|
| 초대장·포스터·무빙포스터 디자인이 끝났을 때 | 3번 "디자인할 것"을 규격에 맞게 내보내 한 폴더에 모아 두기 |
| 전시 날짜·마감 시각이 확정됐을 때 | 4번 "받아 올 정보" 정리하기 |
| **2학기 개강주 (권장)** | Claude에게 넘겨 아카이브에 올리기 (아래 6번). 올리는 순간 첫 화면의 "최신 전시"가 올해로 바뀌고 `UPCOMING EXHIBITION`으로 보임 |
| 전시 기간 | 할 일 없음 (문구 자동 변경) |

자료를 올리기 전까지는 지난해 전시가 `LATEST EXHIBITION`으로 첫 화면에 걸려 있습니다. 서두르지 않아도 사이트가 비거나 깨지지 않습니다.

## 6. Claude에게 이렇게 말하면 됩니다

자료를 컴퓨터의 한 폴더에 모아 둔 뒤, 물려받은 Claude 계정에서 아래처럼 요청하세요. 예시는 2027년 기준입니다.

> 아카이브 사이트에 2027년을 추가해줘. 저장소 README를 먼저 읽고 진행해줘.
> - 자료 폴더: (폴더 위치) — 초대장, 사물 뺀 초대장, 포스터, 무빙포스터가 들어 있어
> - 전시 타이틀: ○○○ (두 줄일 때는 ○○ / ○○)
> - 전시 기간: 2027-11-○○ ~ 2027-11-○○ ○○시 마감
> - 오프닝: 2027-11-○○ (○) ○○:○○, 장소 ○○○
> - 대표색: #○○○○○○

Claude가 파일 이름 정리, 영상 변환, 사이트 반영, 배포 확인까지 하고 결과를 알려 줍니다.
끝나면 `khid.exhibit.khu.ac.kr`을 열어 아래를 직접 확인해 보세요.
- ☐ 첫 화면 초대장 더미 맨 위에 올해 초대장이 있다
- ☐ 첫 화면 문구가 `UPCOMING EXHIBITION`이고, 아래에 올해 기수와 타이틀이 보인다
- ☐ 연혁에서 올해를 고르면 무빙포스터가 재생된다
- ☐ 포스터 모음에 올해 포스터가 있다
- ☐ 휴대폰으로도 열어서 같은 것들이 보인다

## 7. 하지 말아야 할 것

- **Vercel·도메인 설정을 바꾸지 않습니다.** 사이트 주소 `khid.exhibit.khu.ac.kr`은 학교 정보처가 등록해 준 값으로 지금 Vercel 프로젝트(`khid-archive-site`)에 연결되어 있습니다. 프로젝트를 새로 만들거나 지우면 학교에 다시 요청해야 합니다.
- **지난 연도 자료를 지우지 않습니다.** 아카이브에서 그해가 사라집니다.
- **사이트 디자인을 매년 바꾸지 않습니다.** 아카이브는 해마다 자료만 쌓는 사이트입니다. 꼭 바꿀 것이 생기면 Claude와 상의하세요.

## 8. 사이트 구조 (간단히)

화면은 위에서부터 세 부분이고, 모두 **연도별 자료를 자동으로 읽어서** 그립니다.

| 구분 | 화면 | 보이는 것 |
|---|---|---|
| Phase 1 | 첫 화면 | 연도별 초대장이 쌓이는 더미 + 최신 전시 안내(문구·기수·타이틀·VISIT 버튼). 더미를 누르면 초대장 넘겨보기 |
| Phase 2 | 연혁 | 연도·전시 타이틀 목록 + 고른 연도의 무빙포스터 |
| Phase 3 | 포스터 모음 | 연도별 포스터, 누르면 크게 보기 + 그해 전시 사이트로 가는 VISIT WEB SITE |

연도 자료는 해마다 폴더 하나씩 쌓입니다. 숫자가 가장 큰 연도가 "최신 전시"가 되어 첫 화면 맨 위에 옵니다.

| 이름 | 무엇 |
|---|---|
| GitHub | 조직 `khuid`, 저장소 `khid-archive-site` (공개 저장소 — 비밀번호·개인 정보는 여기 적지 않기) |
| Vercel | 팀 `khid`, 프로젝트 `khid-archive-site`. 저장소에 올리면 자동으로 사이트에 반영 |
| 방문자 통계 | Google Analytics 4 |

## 9. Claude·개발용 메모

여기부터는 Claude(또는 개발 담당)가 작업할 때 보는 부분입니다. 디자이너는 읽지 않아도 됩니다.

### 새 연도 추가 작업
연도 폴더 `public/exhibitions/YYYY/`를 만들고 아래 이름으로 넣는다. 이름이 정확해야 인식된다(`src/lib/exhibitions.ts`). 없으면 에러 없이 그 자리만 비므로 빠짐없이 확인할 것.

| 파일 | 받은 자료 | 처리 |
|---|---|---|
| `invitation.png` | 초대장 | 1320×1320 투명 PNG인지 확인 |
| `invitation-plain.png` | 사물을 뺀 초대장 (있을 때만) | `invitation.png`와 같은 캔버스인지 확인. 없으면 넘겨보기에서 `invitation.png`를 씀 |
| `poster.png` / `poster.jpg` | 포스터 | |
| `moving-poster.mp4` | 무빙포스터 | **MP4(H.264)로 변환**(`.mov`는 인식 안 됨, 용량도 큼). 2024년 105MB → 765KB 사례 참고 |
| `info.json` | 정보 | `exhibition-template/info.json` 복사해 채움 |

`info.json` 항목:

| 항목 | 값 | 예시 (2026) |
|---|---|---|
| `titleKo` / `titleEn` | 사이트에는 `titleEn` 우선, 비면 `titleKo`. 연혁 줄바꿈은 `\n` | `"THIS IS NOT\nGRADUATION"` |
| `startDate` | 시작, `"YYYY-MM-DD"` 또는 `"YYYY-MM-DD HH:mm"` (한국 시간) | `"2026-11-11"` |
| `endDate` | 마감, 같은 형식. 시각을 빼면 그날 밤 12시까지 | `"2026-11-16 20:00"` |
| `keyColor` | `#RRGGBB` | `"#1980FF"` |
| `href` | **보통 적지 않음** — 없으면 `https://khid.grad.khu.ac.kr/<연도>`로 자동 연결(`src/lib/exhibitions.ts`). 다른 주소일 때만 적고, 그해 전시 사이트가 아예 없으면 `""`(VISIT WEB SITE 숨김, 예: 2023) | (적지 않음) |
| `openingDate`, `venue` | 기록용 | `""` |

- 시작·마감은 **매년 사용자에게 확정값을 물어볼 것.** 지난해 값을 쓰지 않는다. 비어 있으면 계속 UPCOMING으로 나온다.
- VISIT은 `khid.grad.khu.ac.kr/<연도>`로 자동 연결되므로, 올린 뒤 그 주소가 실제로 열리는지(연도별 사이트 저장소 `khuid/khid-grad`에 그해가 추가됐는지) 확인할 것. 아직 안 열렸으면 사용자에게 알린다.
- 커밋·푸시 후 Vercel 배포가 **Ready**인지, 실제 사이트에 반영됐는지 확인할 것.

### 배포 주의
- Vercel 무료 요금제(Hobby)는 **Vercel 계정에 연결된 GitHub 계정이 만든 커밋만 배포**한다. 다른 작성자로 커밋하면 에러 없이 사이트가 이전 상태로 남는다. 저장소의 `git config user.name/user.email`을 그 계정으로 맞춘 뒤 커밋한다.
- 도메인 `khid.exhibit.khu.ac.kr`은 Vercel 프로젝트 `khid-archive-site`에 연결되어 있다. Vercel이 안내하는 CNAME 값은 프로젝트마다 다르므로 다른 프로젝트로 옮기지 않는다.

### 파일 위치
```bash
npm install
npm run dev        # http://localhost:3000
npm run build
```

| 파일 | 내용 |
|---|---|
| `public/exhibitions/YYYY/` | 연도 자료 (폴더 하나 = 아카이브의 한 해) |
| `exhibition-template/` | 새 연도 `info.json` 양식 + 자료 규격 상세 |
| `src/lib/exhibitions.ts` | 연도 폴더를 읽어 목록을 만듦 (파일 이름 규칙) |
| `src/lib/exhibitionPhase.ts` | 첫 화면 문구 UPCOMING / ONGOING / LATEST 판단 |
| `src/lib/pile.ts` | 첫 화면 초대장 더미 배치 `PILE_LAYOUT` |
| `src/components/Phase1Hero.tsx` | Phase 1 첫 화면 |
| `src/components/InvitationViewer.tsx` | 초대장 넘겨보기 |
| `src/components/Phase2Timeline.tsx` | Phase 2 연혁 |
| `src/components/Phase3Grid.tsx` | Phase 3 포스터 모음 |
| `src/app/og/` | 링크 미리보기 이미지 (최신 연도 초대장으로 자동 생성) |
