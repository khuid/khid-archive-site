# 연도 추가하는 법

새 연도를 추가하려면 `public/exhibitions/` 안에 **연도 이름으로 된 폴더**(예: `2027`)를 하나 만들고, 이 `_template` 폴더에 있는 4개 파일을 그대로 복사해서 값만 채우면 됩니다. 코드는 건드릴 필요 없습니다 — 폴더가 있으면 자동으로 사이트에 반영됩니다.

## 필요한 파일 4개

| 파일명 | 내용 | 형식 |
|---|---|---|
| `poster.jpg` 또는 `.png` | 포스터 (히어로 + 그리드에 공용으로 쓰임) | JPG/PNG |
| `invitation.jpg` 또는 `.png` | 초대장 (홈 화면 쌓임 애니메이션용) | JPG/PNG |
| `moving-poster.mp4` | 무빙포스터 | **MP4(H.264)만 인식됩니다** |
| `info.json` | 국/영문 타이틀, 날짜, 장소, 키컬러 | JSON |

## 키컬러

`info.json`의 `keyColor`에 그해 대표색을 `#RRGGBB` 형식으로 넣으면 홈 화면 "VISIT ○○○○ ON-LINE EXHIBITION" 링크 색이 그 색으로 바뀝니다. 비워두면 흰색으로 나옵니다.
검은 배경 위에 글자로 쓰이니 너무 어두운 색(남색·짙은 갈색 등)은 피해주세요.

## ⚠️ 무빙포스터는 꼭 MP4로 변환해서 올리세요

프리미어/애프터이펙트에서 그냥 내보내면 보통 `.mov`(퀵타임, ProRes) 파일이 나오는데, 이건:
- 웹 브라우저에서 재생이 안 될 수 있음 (크롬 등 미지원)
- 용량이 엄청 큼 (10초짜리가 100MB 넘기도 함)

**MP4로 변환하고 올려주세요.** 변환 안 된 파일을 올리면 코드가 그냥 못 찾아서 무빙포스터 없이(포스터 이미지만) 표시됩니다 — 에러는 안 나지만 영상이 안 보여요.

변환 방법:
- Claude(졸준위 공용 계정 세션)에게 변환 요청하면 자동으로 처리해줌 (권장)
- 또는 직접: [HandBrake](https://handbrake.fr/)(무료 프로그램)로 `.mov` 파일을 열어서 Format을 MP4로, Video Codec을 H.264로 설정 후 내보내기

참고로 2024년 영상은 105MB 원본을 MP4로 변환해서 **765KB**가 됐습니다 — 화질 차이는 거의 없습니다.
